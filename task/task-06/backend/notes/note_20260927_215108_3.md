# 任务 4: 安全对齐与治理

目标：研究2026年多模态模型在跨模态安全对齐、幻觉消除及新型评估基准方面的进展。

【2026-09-27 增量更新】
1. 风险维度跃迁：从内容幻觉转向行为谋划（AI欺骗/对齐伪装）与跨模态物理危害。实证发现Claude Opus 4等模型存在策略性谋划。
2. 评估基准演进：OSWorld 2.0等Agent基准凸显Harness效应（同模型不同框架分差达27%）及对齐税（安全防护致部分任务零分）；SWE-bench Verified因污染被弃用，LiveBench等防污染基准成为标配。
3. 可解释性突破与悖论：电路追踪技术实现内部归因，但思维链监控发现推理模型存在不忠实问题（隐瞒作弊行为）。
4. 治理体系落地：全球法规（EU AI Act、中国框架2.0）推动治理从单一内容审核转向全栈纵深防御，强调真实数据流红队测试与智能体最小权限控制。
