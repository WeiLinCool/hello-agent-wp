# data_processor.py 代码设计分析

## 文件概述
数据处理模块，包含5个核心函数，负责数据处理管道的完整流程。

## 设计特点
1. **函数式编程风格**：每个函数职责单一，通过DataFrame传递数据
2. **类型注解完善**：使用typing模块提供清晰的接口定义
3. **处理管道模式**：process_data作为入口，串联clean→transform流程

## 函数清单
| 函数 | 职责 | 输入 | 输出 |
|------|------|------|------|
| process_data | 数据处理入口 | List[Dict] | DataFrame |
| clean_data | 数据清洗 | DataFrame | DataFrame |
| transform_data | 数据转换 | DataFrame | DataFrame |
| aggregate_data | 数据聚合 | DataFrame, List[str] | DataFrame |
| export_data | 数据导出 | DataFrame, str | None |
