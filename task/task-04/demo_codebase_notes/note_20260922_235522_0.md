# 代码库结构分析

## 项目结构

```
./
├── __init__.py          # 包初始化文件（版本1.0.0）
├── models.py            # 数据模型模块
├── api_client.py        # API客户端模块
├── data_processor.py    # 数据处理模块
└── utils.py             # 工具函数模块
```

## 模块功能

| 模块 | 功能 | 主要类/函数 |
|------|------|-------------|
| models.py | 数据模型定义 | User, Product, Order, Transaction |
| api_client.py | 外部API交互 | APIClient (GET/POST/PUT/DELETE) |
| data_processor.py | 数据处理转换 | process_data, clean_data, transform_data |
| utils.py | 通用工具函数 | load_config, validate_email, format_size |

## 技术栈
- Python 3.x
- 使用 dataclasses 定义数据模型
- 使用 pandas 进行数据处理
- 使用 requests 进行HTTP请求
