# 代码库结构探索结果

## 项目概述
这是一个 Python 数据应用项目，包含 API 客户端、数据处理、数据模型和工具函数四个核心模块。

## 文件结构
```
.
├── __init__.py          # 包初始化，版本号 1.0.0
├── api_client.py        # API 客户端模块
├── data_processor.py    # 数据处理模块
├── models.py            # 数据模型模块
└── utils.py             # 工具函数模块
```

## 模块详情

### 1. api_client.py - API 客户端
- **类**: APIClient
- **功能**: HTTP 请求封装（GET/POST/PUT/DELETE）
- **依赖**: requests
- **待完善**: 重试逻辑、错误处理、确认机制

### 2. data_processor.py - 数据处理
- **核心函数**: 
  - process_data() - 处理原始数据
  - clean_data() - 清理空值和异常值
  - transform_data() - 数据转换
  - aggregate_data() - 数据聚合
  - export_data() - 导出到 CSV
- **依赖**: pandas

### 3. models.py - 数据模型
- **数据类**:
  - User - 用户模型
  - Product - 产品模型（含库存检查、折扣计算）
  - Order - 订单模型（含总额计算）
  - Transaction - 交易模型
- **使用**: Python dataclass

### 4. utils.py - 工具函数
- **功能**:
  - load_config/save_config - 配置管理（JSON格式）
  - get_timestamp - 时间戳获取
  - ensure_dir - 目录创建
  - format_size - 文件大小格式化
  - validate_email - 邮箱验证

## 技术栈
- Python 3.x
- requests (HTTP)
- pandas (数据处理)
- dataclasses (数据模型)
