# 代码库结构分析

## 项目概述
这是一个Python项目，版本1.0.0，主要实现了一个电商/订单管理系统的基础框架。

## 目录结构
```
.
├── __init__.py        # 包初始化文件，定义版本号
├── models.py          # 数据模型模块
├── api_client.py      # API客户端模块
├── data_processor.py  # 数据处理模块
└── utils.py           # 工具函数模块
```

## 模块功能

### 1. models.py - 数据模型
- User: 用户模型（id, username, email, created_at, is_active）
- Product: 产品模型（id, name, category, price, stock）
- Order: 订单模型（id, user_id, products, total_amount, status）
- Transaction: 交易模型（id, order_id, amount, payment_method）

### 2. api_client.py - API客户端
- APIClient类：封装HTTP请求（GET/POST/PUT/DELETE）
- 支持Bearer Token认证
- 使用requests库

### 3. data_processor.py - 数据处理
- process_data: 处理原始数据
- clean_data: 清理空值和重复数据
- transform_data: 数据转换
- aggregate_data: 数据聚合
- export_data: 导出到CSV
- 使用pandas库

### 4. utils.py - 工具函数
- load_config/save_config: 配置管理（JSON格式）
- get_timestamp: 获取时间戳
- ensure_dir: 创建目录
- format_size: 格式化文件大小
- validate_email: 邮箱验证
