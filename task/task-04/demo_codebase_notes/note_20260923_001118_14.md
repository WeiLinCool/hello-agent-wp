# data_processor.py 代码设计分析

## 文件概述
数据处理模块，提供数据清洗、转换、聚合和导出功能

## 设计分析
1. **职责划分**：5个函数各司其职，职责单一
2. **数据流向**：原始数据 → 清洗 → 转换 → 聚合/导出
3. **依赖**：pandas（数据处理）、typing（类型提示）
